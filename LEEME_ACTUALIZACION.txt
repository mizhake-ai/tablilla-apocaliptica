(El Agujero Negro queda desactivado y al final de la lista, reservado para el ultimo evento.)

COMO USARLA (GitHub, navegador):
1. Descomprime este zip.
2. Tu repositorio > Add file > Upload files.
3. Arrastra TODO el contenido (carpeta "src", "gradle.properties", "LEEME.md"). Se reemplazan los archivos con el mismo nombre.
4. Commit changes. GitHub Actions compila solo.
5. Actions > ultimo "Compilar mod" > Artifacts > tablilla-apocaliptica-jar.

Si sale error rojo al compilar, mandame las lineas que dicen "error:".
